# TokiMate Pro v0.7.2

本人用の勤怠・給与自己検算PWAです。

- フレックスタイム制：毎月1日〜末日清算
- 日曜日：法定休日として0:00〜24:00を別集計
- 土曜・日本の祝日：特休（非法定休日）を初期表示
- 夜勤：日付境界で分割して集計
- 月またぎ勤務：各清算月へ分割して集計
- 平日は未入力、土曜・祝日は特休、日曜は公休を初期表示（勤務種別は日別に任意入力）
- 出勤・特休・公休・非番・有休・出勤日・忌引き・その他＋追加勤務種別（従来の「日勤」記録は「出勤」として表示）
- 長押し出退勤打刻
- 月間勤務シート（矢印月送り・長押し月一覧）／日別編集
- 会社規定勤務時間（平日×8時間）を超えた時間を「時間外」として表示
- 会社休憩ルール：6時間未満45分、6時間以上60分を自動提案
- 法定休憩の参考表示
- 36協定チェック：月45h・年360hの原則、特別条項時の上限確認、年720h、単月100h未満、2〜6か月平均80h、45h超年6回
- 割増賃金概算と給与明細照合
- 基本給＋算入対象手当から割増賃金の計算基礎月額を自動算出
- 固定キャラクター：しおり、キャリー、たける、ソジュン、まる、ロボたん
- テーマ色変更
- 端末内Q&A、音声読み上げ、対応ブラウザで音声入力
- 1日1回のおみくじ＋キャラ別演出
- 残業抑制ポイント＋キャラクターアイテム交換
- IndexedDB端末内保存、AES-GCM暗号化対応バックアップ

## 夜勤・月またぎの扱い
勤務開始日と終了時刻から日付境界を判定し、実労働・深夜・法定休日を日付単位で分割します。日曜をまたぐ勤務は、日曜0:00〜24:00に該当する部分だけを法定休日労働として扱います。

通常休憩は休憩時刻そのものを保持していないため、日曜またぎ・月またぎでは各日区間の勤務時間比で按分します。深夜休憩は「うち22:00〜翌5:00の休憩」入力を使って深夜時間から控除します。

## ポイント
月末確定後、会社規定勤務時間を超えた時間外に応じて一度だけ付与します。
- 0〜10h: 1000pt
- 10〜20h: 750pt
- 20〜30h: 500pt
- 30〜45h: 250pt
- 45h超: 0pt

勤務記録を少なく入力することを誘発しないよう、当月中は見込み表示のみで、確定済みの過去月にだけ付与します。

## 注意
法令・給与の最終判断用ではありません。会社の就業規則、賃金規程、36協定、労使協定を優先してください。
日本の祝日判定は静的ロジックを含むため、臨時の祝日変更等は更新が必要です。
