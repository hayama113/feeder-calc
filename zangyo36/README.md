# RecoLife v0.6

社内指定勤怠アプリの運用イメージを参考にした、本人用の勤怠・給与自己検算PWAです。

- フレックスタイム制：毎月1日〜末日清算
- 日曜日：法定休日として別集計
- 土曜・日本の祝日：特休を初期表示
- 出勤・出勤日・特休・公休・忌引き・有休・非番・その他＋追加勤務種別
- 長押し出退勤打刻
- 月間勤務シート
- 36協定上限チェック
- 割増賃金概算と給与明細照合
- 固定キャラクター：しおり、キャリー、たける、ソジュン、まる、ロボたん
- テーマ色変更
- 端末内Q&A、音声読み上げ、対応ブラウザで音声入力
- 1日1回のおみくじ＋キャラ別演出
- 残業抑制ポイント＋キャラクターアイテム交換
- IndexedDB端末内保存、AES-GCM暗号化対応バックアップ

## ポイント
月末確定後、法定時間外に応じて一度だけ付与します。
- 0〜10h: 1000pt
- 10〜20h: 750pt
- 20〜30h: 500pt
- 30〜45h: 250pt
- 45h超: 0pt

勤務記録を少なく入力することを誘発しないよう、当月中は見込み表示のみで、確定済みの過去月にだけ付与します。

## 注意
法令・給与の最終判断用ではありません。会社の就業規則、賃金規程、36協定、労使協定を優先してください。
日本の祝日判定は静的ロジックを含むため、臨時の祝日変更等は更新が必要です。
