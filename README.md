## 2026-08-27 電線管自動選定

- IV、EM-IE/Fおよび既存CV系ケーブルの複数入力に対応。
- メーカーを特定しない参考外径と、電線管の参考内径から占有率を算出。
- 占有率上限は32%（標準）または48%（条件付き）から選択。
- 選択配管のOK/NG、実占有率、最小配管、施工条件を考慮した推奨配管を表示。
- 占有率基準を満たす最小配管を推奨配管として表示。
- 長距離、曲がり、複数線種、48%基準、将来増設の条件では、施工上の注意として1サイズ上の検討を案内。
- 計算画面上部の入口メニューに「電線管自動選定」を追加し、計算欄へ直接移動可能。
- 電線管自動選定を低圧幹線計算から分離し、専用画面として独立。

- 保護管選定結果に適用基準、必要内径・面積、推奨管内径、面積または内径の裕度を追加。
